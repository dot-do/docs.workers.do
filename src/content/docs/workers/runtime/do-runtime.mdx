# The .do Runtime

The .do platform provides a universal `$` runtime that gives every worker access to powerful built-in primitives without configuration. No bindings to set up, no environment variables to manage - just write code.

## Overview

Every worker on the .do platform runs in a context where these primitives are always available:

```typescript
export default {
  async fetch(request) {
    // All primitives are available in the $ runtime
    const user = await $.db.users.findOne({ email: request.headers.get('user-email') })

    const response = await $.ai.generateText({
      prompt: `Greet ${user.name} personally`,
      model: 'claude-3-5-sonnet-20241022'
    })

    await $.send.email({
      to: user.email,
      subject: 'Welcome back!',
      body: response
    })

    return new Response(response)
  }
}
```

## Runtime Primitives

### `$.ai` - AI Generation

Access AI models for text generation, embeddings, and chat without managing API keys or rate limits.

```typescript
// Text generation
const text = await $.ai.generateText({
  prompt: 'Write a haiku about coding',
  model: 'claude-3-5-sonnet-20241022'
})

// Embeddings
const vector = await $.ai.embed({
  text: 'The quick brown fox',
  model: 'text-embedding-3-small'
})

// Chat
const response = await $.ai.chat({
  messages: [
    { role: 'user', content: 'What is TypeScript?' }
  ],
  model: 'gpt-4'
})

// Streaming
const stream = await $.ai.generateStream({
  prompt: 'Write a long story',
  model: 'claude-3-5-sonnet-20241022'
})

for await (const chunk of stream) {
  console.log(chunk)
}
```

**Supported Models:**
- Anthropic Claude (Sonnet 3.5, Opus 3, Haiku 3)
- OpenAI (GPT-4, GPT-3.5-turbo)
- Google Gemini (Pro, Flash)
- Cloudflare Workers AI (Llama 3, Mistral)

### `$.api` - HTTP Requests

Make authenticated requests to platform APIs with automatic retries and rate limiting.

```typescript
// GET request
const data = await $.api.get('/users/123')

// POST with data
const created = await $.api.post('/users', {
  name: 'Alice',
  email: 'alice@example.com'
})

// PUT update
const updated = await $.api.put('/users/123', {
  name: 'Alice Smith'
})

// DELETE
await $.api.delete('/users/123')

// Custom options
const response = await $.api.request('/data', {
  method: 'POST',
  headers: { 'X-Custom': 'value' },
  body: JSON.stringify({ data: 'value' })
})
```

### `$.db` - Database Queries

Query PostgreSQL and ClickHouse databases with a unified interface.

```typescript
// Query rows
const users = await $.db.query({
  sql: 'SELECT * FROM users WHERE active = ?',
  params: [true]
})

// Single row
const user = await $.db.queryOne({
  sql: 'SELECT * FROM users WHERE id = ?',
  params: [123]
})

// Execute command
await $.db.execute({
  sql: 'UPDATE users SET last_seen = NOW() WHERE id = ?',
  params: [123]
})

// Transactions
await $.db.transaction(async (tx) => {
  await tx.execute('INSERT INTO orders ...')
  await tx.execute('UPDATE inventory ...')
})

// ORM-style (optional)
const activeUsers = await $.db.users.find({ active: true })
const user = await $.db.users.findOne({ id: 123 })
await $.db.users.insert({ name: 'Bob', email: 'bob@example.com' })
await $.db.users.update({ id: 123 }, { last_seen: new Date() })
await $.db.users.delete({ id: 123 })
```

**Databases:**
- PostgreSQL (via Neon) - Primary datastore
- ClickHouse - Analytics and time-series

### `$.on` - Event Handlers

Subscribe to events and handle them reactively.

```typescript
// HTTP request handler
$.on('fetch', async (request) => {
  return new Response('Hello!')
})

// Scheduled tasks
$.on('scheduled', async (event) => {
  console.log('Cron triggered:', event.cron)
})

// Queue messages
$.on('queue', async (batch) => {
  for (const message of batch.messages) {
    await processMessage(message)
    message.ack()
  }
})

// Webhooks
$.on('webhook.stripe', async (event) => {
  if (event.type === 'payment_intent.succeeded') {
    await fulfillOrder(event.data)
  }
})

// Custom events
$.on('user.created', async (user) => {
  await $.send.email({
    to: user.email,
    subject: 'Welcome!',
    template: 'welcome'
  })
})
```

### `$.send` - Messaging

Send emails, push notifications, WebSocket messages, and more.

```typescript
// Email
await $.send.email({
  to: 'user@example.com',
  from: 'noreply@yourapp.com',
  subject: 'Welcome!',
  html: '<h1>Hello!</h1>',
  text: 'Hello!'
})

// Email with template
await $.send.email({
  to: user.email,
  template: 'welcome',
  data: { name: user.name }
})

// Bulk email
await $.send.emails([
  { to: 'alice@example.com', subject: 'Hi Alice' },
  { to: 'bob@example.com', subject: 'Hi Bob' }
])

// WebSocket message
await $.send.websocket({
  connection: ws,
  message: { type: 'update', data: newData }
})

// Server-Sent Events
await $.send.sse({
  channel: 'notifications',
  event: 'message',
  data: { text: 'New notification!' }
})

// Push notification
await $.send.push({
  subscription: userSubscription,
  title: 'New message',
  body: 'You have a new message',
  icon: '/icon.png'
})
```

### `$.every` - Scheduled Tasks

Schedule recurring tasks with cron expressions.

```typescript
// Run every hour
$.every('0 * * * *', async () => {
  await cleanupExpiredSessions()
})

// Run daily at 9 AM
$.every('0 9 * * *', async () => {
  await sendDailyDigest()
})

// Run every 5 minutes
$.every('*/5 * * * *', async () => {
  await checkHealthStatus()
})

// Human-readable syntax
$.every('1 hour', async () => {
  await syncData()
})

$.every('1 day', async () => {
  await generateReport()
})

$.every('5 minutes', async () => {
  await pollAPI()
})

// With context
$.every('1 hour', async (ctx) => {
  console.log('Last run:', ctx.lastRun)
  console.log('Next run:', ctx.nextRun)
  await performTask()
})
```

## Authentication Context

Every request automatically includes user authentication context:

```typescript
export default {
  async fetch(request, $) {
    // User context is automatically populated via OAuth
    const user = $.user

    if (!user) {
      return new Response('Unauthorized', { status: 401 })
    }

    console.log('User:', user.id, user.email, user.name)
    console.log('Roles:', user.roles)
    console.log('Tenant:', user.tenantId)

    // Check permissions
    if (user.hasRole('admin')) {
      // Admin-only logic
    }

    // Tenant-scoped queries
    const data = await $.db.query({
      sql: 'SELECT * FROM items WHERE tenant_id = ?',
      params: [user.tenantId]
    })

    return Response.json({ data })
  }
}
```

## Error Handling

The runtime provides consistent error handling:

```typescript
try {
  const result = await $.ai.generateText({
    prompt: 'test',
    model: 'claude-3-5-sonnet-20241022'
  })
} catch (error) {
  if (error.code === 'RATE_LIMIT') {
    // Handle rate limit
    console.log('Retry after:', error.retryAfter)
  } else if (error.code === 'QUOTA_EXCEEDED') {
    // Handle quota
  } else {
    // Other errors
    console.error(error.message)
  }
}
```

## Type Safety

Full TypeScript support with autocomplete:

```typescript
import type { RuntimeContext } from '.do/runtime'

export default {
  async fetch(request: Request, $: RuntimeContext) {
    // Full autocomplete for $ primitives
    const text = await $.ai.generateText({
      prompt: 'test',
      // TypeScript knows available models
      model: 'claude-3-5-sonnet-20241022'
    })

    return Response.json({ text })
  }
}
```

## Comparison with Standard Workers

| Feature | Standard Workers | .do Platform |
|---------|------------------|--------------|
| AI Access | Setup providers manually | `$.ai` built-in |
| Database | Configure bindings | `$.db` built-in |
| Scheduled Tasks | Add cron triggers | `$.every()` built-in |
| Email | Use Resend/SendGrid | `$.send.email()` built-in |
| Authentication | Implement yourself | `$.user` automatic |
| WebSockets | Manual setup | `$.send.websocket()` built-in |
| Configuration | wrangler.toml | YAML frontmatter |

## Best Practices

**1. Use the $ runtime for everything:**
```typescript
// ✅ Good - Use $ primitives
const data = await $.db.query('SELECT ...')

// ❌ Avoid - Direct API calls
const response = await fetch('https://api.example.com/data')
```

**2. Handle errors gracefully:**
```typescript
// ✅ Good - Catch and handle
try {
  await $.send.email({ ... })
} catch (error) {
  console.error('Email failed:', error)
  // Fallback logic
}
```

**3. Leverage automatic auth:**
```typescript
// ✅ Good - Use $.user
if (!$.user) {
  return new Response('Unauthorized', { status: 401 })
}

// ❌ Avoid - Manual JWT parsing
const token = request.headers.get('authorization')
const decoded = jwt.verify(token, secret)
```
