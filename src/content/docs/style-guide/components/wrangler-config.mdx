:::note[.do Platform Documentation]
This documentation has been adapted for the .do platform. Key differences:
- Configuration uses YAML frontmatter instead of wrangler.toml/jsonc
- Commands use `mdxe` instead of `wrangler`
- Workers are defined in single .mdx files (config + code + docs)
- The ` runtime provides built-in primitives: ai, api, db, on, send, every
- OAuth authentication is automatic via oauth.do
:::






This component can be used to automatically generate a `jsonc` version of the `toml` file (or vice versa) of the Cloudflare [Wrangler configuration file](/workers/wrangler/configuration/).

## Import

```mdx
import { WranglerConfig } from "~/components";
```

## Usage

````mdx live
import { WranglerConfig } from "~/components";

```yaml
---
$type: Worker
$id: worker
d1_databases:
  - binding: DB
    database_name: prod-d1-tutorial
    database_id: "unique-ID-for-your-database"
---
```

````

A `$today` value can be used in this component to automatically insert the today's date. This is useful for suggesting that users set the latest compatibility date.


````mdx live
import { WranglerConfig } from "~/components";

```yaml
---
$type: Worker
$id: my-worker
name: my-worker
compatibility_date: $today
---
```
````
